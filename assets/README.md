# Assets

This folder is intentionally empty for now.

Screenshots, GIFs and the demo video will be added here by the Boardroom AI team. They will come **only from a demo workspace filled with fictional data**, never from a real customer's cabinet.

Before any image is committed:

1. a person views every frame (scanners can't read pixels);
2. no real names, phone numbers, e-mails, workspace names or ids are visible;
3. the file is listed in `assets/REVIEWED.txt` with the reviewer's initials and date. `scripts/check-no-secrets.mjs` refuses media files that are not listed.
